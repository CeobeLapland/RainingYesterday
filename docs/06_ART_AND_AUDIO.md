# 06 · 美术与音乐风格规范

> 本文件固定《昨夜有雨》的视觉与听觉方向，供 UI、地图、图标、AR 贴片、音效、配乐所有视觉/声音资产落地时统一引用。目标：**温暖、治愈、田园、松弛**；参考《星露谷物语》的情绪氛围，但**明确不做像素风**。

## 1. 风格定位（一句话）

> 一场发生在真实校园里的、带着暖光的慢生活手账 —— 视觉像"柔和的绘本插画"，听觉像"窗边的 Lo-fi 陪伴"。

情绪关键词：温暖、治愈、松弛、田园、手作感、慢节奏、低压力、有呼吸感。

## 2. 参考与边界

**继承自《星露谷物语》的是"情绪"，不是"画法"**：

- 继承：暖色调田园、四季流转的松弛感、把平凡日常画得可爱、音乐是陪伴而非主角。
- 放弃：像素块渲染、8-bit 音乐音源、高节奏经济感。

**边界（本项目定位）**：柔和扁平 + 手绘感，去像素、去写实、去暗黑。

## 3. 视觉语言

### 3.1 渲染方式

- **柔和扁平插画（soft flat illustration）**，非像素、非写实、非赛璐璐强描边。
- 允许极细的同色描边或无线条；用**色块 + 柔和渐变 + 轻微噪点/纸纹**营造"手作感"。
- 禁用：像素块、大面积纯平色、生硬直线切割。

### 3.2 形态

- 一切**圆润**：大圆角、圆弧，无锐利边角、无锯齿轮廓。
- 角色约 **2 头身 的 Q 版**，眼睛以圆润点状/椭圆表达，表情温柔。
- 物件"膨胀可爱"化，比例略夸张、去棱角（树、房子、图标都像被"软化"过）。

### 3.3 光照与阴影

- 恒定温暖环境光，偏好**黎明 / 黄昏**的柔光氛围。
- 低对比、柔阴影（cf. 无重阴影、无硬边投影）。
- 整体亮度中高，画面"发亮但不刺眼"。

## 4. 色板

基调：**暖调 + 低饱和 + 中高亮度**。以下为起步色板，可微调但须保持同一情绪。

### 4.1 基底（浅暖，大面积背景）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 纸白 paper | `#FCF9F3` | 页面底、留白 |
| 奶油米白 cream | `#F7F1E5` | 卡片、surface |
| 亚麻浅卡其 linen | `#EFE6D3` | 次级底、分隔 |

### 4.2 主色（暖）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 金盏黄 marigold | `#F2C14E` | 主强调、收获、记忆之光 |
| 杏橙 apricot | `#F0A868` | 主按钮、暖强调 |
| 陶土 terracotta | `#C97B5F` | 强调、节日、陶/砖 |

### 4.3 辅助（自然）

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 鼠尾草绿 sage | `#A3B88E` | 草坪、树叶、自然 |
| 苔绿 moss | `#6F8C63` | 深草、树林 |
| 雾蓝 mist blue | `#A9C0C9` | 湖面、天空、静谧 |
| 暖棕 wood | `#A97B5F` | 木、老建筑 |
| 柔樱粉 blush | `#E9B8B0` | 樱花、温柔点缀 |

### 4.4 文字

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 暖棕黑 | `#4A3F35` | 主文字（不用纯黑） |
| 暖灰褐 | `#8A7B6A` | 次要文字 |

### 4.5 色彩原则

- 低饱和、暖调、对比柔和；**避免大面积纯黑/纯白**。
- 每个画面一个主色 + 一个点缀色，克制用色。
- 季节轮换 = 在 4.1 基底不变的前提下，替换 4.2/4.3 的点缀色比例（春偏柔樱粉、夏偏鼠尾草绿、秋偏金盏/陶土、冬偏雾蓝）。

## 5. 字体与排版

- 中文：圆体类（如阿里巴巴普惠体圆体、HarmonyOS Sans 圆体方向），柔和、无棱角。
- 英文与数字：圆润无衬线。
- 排版：留白充足、行距松、字号层级清晰；正文不压黑底。

## 6. UI 风格

- 在 **Material3** 基础上"软化"：大圆角（16–24dp）、柔和 elevation、暖色 surface（奶油米白）。
- 主按钮：杏橙/金盏实心圆角；次按钮：浅暖描边。
- 图标：圆润线性或小面块填充，统一 stroke 圆头。
- 动效：缓动柔和（ease-out、慢速），避免弹跳过猛。

## 7. 双层世界的视觉表达

游戏有"表层（生活）/ 深层（神秘）"两层，视觉要**统一中有反差**，但**不恐怖**：

- **表层**：明亮、暖、饱和稍高，暖光充足。
- **深层（翻面）**：同一画面明度下调 + 叠加一层雾蓝/靛灰滤镜（约 `#5C6B7A`），色彩去饱和；**保留一点克制的暖光点缀**（金盏黄 `#F2C14E` 作为"记忆/线索之光"），营造"幽美静谧"而非"惊悚"。
- 禁止：血红、纯黑、恐怖音画、跳吓。

## 8. 资产规范

| 类目 | 格式 | 说明 |
| --- | --- | --- |
| 图标 | SVG | 圆润、线/面统一 |
| 角色 / 物件 / 场景插画 | PNG（2x/3x）或 SVG | 走 §3 柔和扁平风格，透明底或米白底 |
| AR 贴片（billboard） | PNG 透明底 + 底部软阴影 | 与 2D 插画同一套风格，P2 使用 |
| 命名 | 蛇形 | `asset` 字段对齐内容 JSON 的 id（`02` §2.11） |

## 9. 音乐风格

- **类型**：Lo-fi / 原声吉他 / 尤克里里 / 钢琴 + 环境音，节奏中慢。
- **情绪**：温暖、松弛、陪伴感，**音量偏低、不抢戏**，循环无缝。
- **场景分层 BGM**：黎明、白天、黄昏、夜晚、雨天、节日、深层（同旋律的空灵变奏）。
- **季节感**：春=轻盈拨弦、夏=明亮吉他、秋=温暖木管/钢琴、冬=静谧弱化。
- 参考氛围 = 星露谷的田园松弛，但音源用真实/软合成器而非 8-bit。

## 10. 音效风格

- 原则：**轻、软、不刺耳**，作为反馈而非打扰。
- 采集：柔和"叮/啵"；发现：温暖短提示音（不刺耳）；脚步：沙沙；UI 点击：软 tap。
- 环境音：风、雨、鸟鸣、蝉鸣、湖边水流，与天气/地点呼应。

## 11. 明确不做

- 不做像素风、不做 8-bit 音乐音源。
- 不做写实建模/写实材质、不做暗黑恐怖/克苏鲁式惊悚。
- 不做高饱和赛博/霓虹、不做密集高对比 UI。
- 音乐不做强节奏电子/摇滚/急促 BGM。

## 12. 落地优先级

- **MVP（M0–M9）**：视觉只做"设计 token + 基础圆润图标 + 暖色主题"这一层，能跑通即可；音乐音效可先用少量授权素材或静音占位，**不阻塞开发**。
- **P1**：完整 UI 主题、图标集、场景色板、按场景补齐音乐、基础音效。
- **P2**：AR 贴片资产、动效细化、完整音效库与深层空灵变奏。

## 项目一句话

一款基于现实地理空间的生活模拟 RPG：玩家用真实定位解锁地图迷雾，把经过的地点、天气、人物、事件记录成"我的世界"，在探索基础上养成、宠物、种田、建造、NPC 交互、实拍识别，拥有软肉鸽元素，并在表层生活之下逐步触达传闻、异常与历史地图。核心：生活记录为本体、神秘为钩子，真实信号优先、模拟兜底；AR 为后期高级解药（P2，MVP 只留接口）。

## 三条贯穿全程的铁律

1. **内容数据驱动**：世界内容（地点、NPC、任务、配方、事件、传闻、异常、主题）全部是 JSON 数据，代码里不硬编码内容。加内容 = 改 JSON，不改引擎。
2. **分两个数据源**：世界内容（静态、一份）与玩家存档（动态、每人一份）必须分开，不混在一个表里。
3. **领域层纯 Kotlin**：游戏规则不依赖 Android、地图 SDK 或 UI，可独立测试、将来可复用到网页版。

## 给 agent 的正确使用方式

- 接到一个阶段任务（见 `05_ROADMAP.md`），先读该阶段所述涉及的 `01` / `02` 章节，再读 `03` / `04` 的相关约束，然后写代码。
- 不确定某个字段含义时，回查 `02_DATA_MODEL.md`，不要自己猜。
- 需要新增内容类型时，先在同文件里补 schema，再实现引擎，最后让编辑器能编辑它。
- 所有产物遵循 `04_CONVENTIONS.md`，不要引入文档之外的架构模式（如不必要的抽象层）。
